Among the metrics listed above, "CPUUsage" is very helpful
for checking your jobs' performance and efficiency.

"CPUUsage" = CPUUSER / CPUhours

It represents the approximate rate of your job's real CPU
usage divided by the total CPU hours allocated to the job.

A CPUUsage value close to 1 generally indicates good CPU
utilization.

If CPUUsage is significantly below 1, your job may be
under-utilizing the resources requested from the cluster.

There can be many reasons for low CPU utilization. Please
consider checking the following:

  - MPI job configuration
  - Number of requested nodes
  - Number of requested CPU cores
  - Whether a shared queue would be more appropriate
  - Multithreading/process configuration
  - Excessive process/thread oversubscription
  - Heavy disk I/O
  - Whether many small jobs can be combined into a larger job

"CPUhours" is the total CPU time allocated to the job,
approximately:

    Elapsed time × CPU count

"CPUSYST" represents CPU time used by the operating system
and related system activity.

"CPUUSER" represents CPU time used by the user's computation.

"MemUsed" represents the maximum memory reported by Slurm.

Depending on the current Slurm configuration, memory usage
can sometimes be accounted for repeatedly for the same
physical memory, particularly with multithreaded jobs.

If this occurs, MemUsed may appear larger than the requested
memory.

A rough estimate in this situation may be obtained by:

    MemUsed / nCPUs
